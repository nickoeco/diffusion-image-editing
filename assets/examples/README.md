# Example image provenance

`astronaut.png` is an unmodified 512×512 RGB export of `skimage.data.astronaut()`
from scikit-image 0.25.2, saved as PNG with Pillow. The image originates from NASA's
Great Images database. The [scikit-image dataset documentation](https://scikit-image.org/docs/0.25.x/api/skimage.data.html#skimage.data.astronaut)
states that it has no known copyright restrictions and was released into the public
domain. It is included as a reproducible natural-image reconstruction input.

The generated Phase 1 gradient/checkerboard test card remains in ignored outputs;
it uses no external assets. Neither example establishes general editing quality.
